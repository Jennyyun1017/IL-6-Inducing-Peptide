# IL-6-Inducing-Peptide
IL-6 Inducing Peptide Prediction is a machine learning/deep learning project for identifying peptides that can induce Interleukin-6 (IL-6) production. The project utilizes peptide sequence-based features to develop predictive models for binary classification of IL-6 inducing and non-inducing peptides, supporting immunology and therapeutic peptide research.
